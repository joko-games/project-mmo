# Project MMO: documentation

A sandbox space game made of blocks, in the spirit of Avorion and StarMade: one server is one
galaxy, and every new player is a probe that wakes up in a star system of its own.

- [Architecture](architecture.md): the workspace, the client, the server, the protocol.
- [Building and running](running.md): how to build, test and play locally.
- [Galaxies](galaxies.md): one server per galaxy, home systems, and how galaxies will link.
- [Game design](design.md): the pitch, the false goal, and what the sandbox is for.
